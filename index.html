03 / GAME DEVELOPMENT

Orbital Arsenal

Gameplay image — AI-enhanced lighting and English interface translation. Click the image to view it full size.

JavaFabricMinecraft

The idea

I worked on a Minecraft mod that adds orbital strikes and reinforcement tools. It brings a science-fiction idea into a block world, with custom controllers, effects and multiplayer support.

What I learned

How game mechanics connect to player input, why multiplayer needs server-side logic, and how testing helps find bugs.

How it works

  1. Choose a target

    The player uses an in-game controller to mark a location.

  2. Call the strike

    The mod processes the request and starts the strike sequence.

  3. See the result

    The strike reaches the target, triggering its effects in the game world.

01 / LANGUAGE LEARNING

Context Reader

JavaScriptTXT / EPUBTranslation

The idea

I worked on a browser-based reader for English texts, with support for Norwegian too. Instead of leaving the book to look up a word, I can select it, see a Russian translation and save it for later.

What I learned

How to work with book files, build a comfortable reading interface and store vocabulary in the browser.

How it works

  1. Open a book

    Upload a TXT or EPUB file, paste text, or try the built-in sample.

  2. Translate in context

    Select a word or phrase to open its translation beside the text.

  3. Build a vocabulary

    Save useful words in a personal dictionary stored in the current browser.

02 / DATA & VIDEO

Shorts Lab

PythonSQLiteYouTube data

The idea

I worked on a local app for researching YouTube Shorts. It keeps video statistics in one place so I can compare videos and follow changes over time.

What I learned

How to collect and organise data, save it in a database and turn numbers into useful charts. More observations make comparisons more useful.

How it works

  1. Collect video data

    Add videos to track and collect available statistics.

  2. Keep a history

    Save repeated observations in a local SQLite database.

  3. Explore the growth

    Filter videos, compare their performance and inspect changes on charts. The app tracks observations; it cannot guarantee future views.
